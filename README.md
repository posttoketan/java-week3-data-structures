## Project Description
This project demonstrates the implementation of fundamental data structures using Java. It covers arrays, linked lists, stacks, queues, binary search trees, and hash maps through practical programming examples.

## Topics Covered

1. **Arrays:** Storing and traversing elements, calculating sum and average.
2. **Linked Lists:** Adding and removing elements using Java LinkedList.
3. **Stack:** Implementing LIFO operations using push(), pop(), and peek().
4. **Queue:** Implementing FIFO operations using offer(), poll(), and peek().
5. **Binary Search Tree:** Inserting nodes and performing inorder traversal.
6. **HashMap:** Storing and retrieving key-value pairs using HashMap.
